
## Universal Data Model (UDM)
A modelling technique, developed by Len Silverston, that represents business entities, attributes, and
relationships as technology-agnostic structures, independent of tooling or storage.

## Canonical data model
A single, business-aligned data structure that source systems are transformed into, so that every
consumer downstream shares one definition of each concept instead of each source's own structure.

## Core data model
A canonical data model that can be built using different modelling techniques, such as the UDM.


## Metadata-driven
An approach where system behavior is derived from declarative metadata
rather than hard-coded logic.

## Ontology (AI context)
A formal representation of domain concepts, relationships, constraints,
and intent suitable for machine reasoning.
